# Post-Quantum Claim Policy

This policy prevents marketing language from getting ahead of cryptographic evidence.

## Current repository status

Winmar Chain Chain ID `12142816` uses EVM-compatible transaction semantics and QBFT Proof of Authority. The post-quantum work in this repository is a staged hybrid-security program.

Phase 1 introduces architecture, evidence requirements, and an attestation registry. It does **not** replace secp256k1 and does **not** make ML-DSA a QBFT consensus rule.

## Terminology

Use **post-quantum cryptography (PQC)** or **quantum-resistant / quantum-resilient security** for cryptography intended to resist future quantum attacks.

Do not imply that Winmar Chain runs on a quantum computer.

## Publication gate

The phrase **"Quantum-Resilient Settlement Layer 1"** may be used as a roadmap or architecture descriptor only when accompanied by a status statement identifying which controls are actually deployed.

A production-wide statement that transactions are quantum-resistant requires documented cryptographic enforcement, reproducible verification evidence, and independent review.
